# تطبيق مراسلة الأولياء – مدرسة السلام الابتدائية

## الحصول على ملف APK (بدون تثبيت أي برنامج)
1. أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي .github) إلى المستودع.
3. افتح تبويب Actions ← "Build APK" ← انتظر 3–5 دقائق حتى يكتمل.
4. من أسفل صفحة التشغيل حمّل Artifact باسم salam-parents-apk (ملف zip فيه app-debug.apk).
5. انقل الملف إلى الهاتف وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة").

## بديل: Android Studio
npm install ثم npx cap add android ثم npx cap sync ثم npx cap open android ثم Build > Build APK.

## إدخال الأرقام
القائمة فارغة عند التثبيت (لا توجد أرقام داخل الكود). يدخلها المستعمل يدويًا أو يستوردها من Excel أو CSV أو VCF أو نص ملصوق.
